How to contribute
-----------------

APPFL is an open-source software project. Contributions of code and ideas from the community are welcome!

.. note::

    Make sure that any contribution is extensively tested and documented.


Core contributors
~~~~~~~~~~~~~~~~~

Core contributors are our project team members and those who are closely collaborating with our team.
These contributors are highly recommended to have direct access to the APPFL GitHub repository so that they can create new branches.

We recommend creating a new branch (e.g., ``myid/newalgo``, ``myid/issue99``) for any development or bug-fixing work. Once the work is complete, please open a pull request, ideally with the reviewer(s) identified.


External contributors
~~~~~~~~~~~~~~~~~~~~~

External contributors are recommended to create a fork of the repository and open a pull request once the contributions are ready to be merged.
