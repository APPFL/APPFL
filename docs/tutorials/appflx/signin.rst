Log in/Sign up
==============

We built a web application that provides privacy-preserving federated learning as a service. To log in,

1. Go to the home page of the web application: `appflx.link <https://appflx.link>`_ or `service.appfl.ai <https://service.appfl.ai>`_

2. If you do not have a Globus account, click **SIGN UP** at the top right of the page, and first check if your organization is in the drop-down list. If so, you can simply log in using your organization credentials. Otherwise, you can register a Globus ID by following the prompts.

3. If you have a Globus account, click **LOGIN IN** at the top right of the page to sign in to the application.
